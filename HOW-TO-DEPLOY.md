# Как загрузить проект на Vercel (без программирования)

## Шаг 1 — создать аккаунт на GitHub
GitHub — это место, где хранится код перед тем как Vercel его заберёт и опубликует.
1. Зайти на github.com → Sign up → завести аккаунт (просто email + пароль)

## Шаг 2 — создать репозиторий и загрузить файлы (через сайт, без программ)
1. На github.com нажать зелёную кнопку **"New"** (или "+" в углу → "New repository")
2. Название — любое, например `caption-generator`
3. Оставить "Public" или выбрать "Private" (не принципиально)
4. Нажать **"Create repository"**
5. На следующей странице найти ссылку **"uploading an existing file"**
6. Перетащить туда ВСЮ папку `deploy-project` целиком (или все файлы из неё) — GitHub сохранит структуру папок автоматически
7. Внизу нажать **"Commit changes"**

## Шаг 3 — подключить Vercel к этому репозиторию
1. Зайти на vercel.com → Sign up → выбрать **"Continue with GitHub"** (это свяжет аккаунты)
2. На главной панели Vercel — **"Add New" → "Project"**
3. Найти в списке репозиторий `caption-generator`, нажать **"Import"**
4. Vercel сам увидит, что это Vite-проект, и настроит сборку автоматически — ничего не нужно менять
5. Перед нажатием "Deploy" — раскрыть раздел **"Environment Variables"** и добавить туда все четыре:
   - `NOWPAYMENTS_API_KEY`
   - `PUBLIC_URL` (впишите после первого деплоя реальный адрес, потом пересохраните)
   - `ACCESS_CODE` → `TAG92`
   - `ANTHROPIC_API_KEY`
6. Нажать **"Deploy"**

## Шаг 4 — после первого деплоя
Vercel даст вам ссылку вида `https://caption-generator-xxxx.vercel.app`. Скопируйте её, вернитесь в Environment Variables и впишите её как `PUBLIC_URL` (без этого шага автоматическое перенаправление на страницу с кодом не будет знать, куда вести). После этого нажмите "Redeploy", чтобы изменения применились.

## Проверка
Откройте `https://ваш-адрес.vercel.app/buy.html` — если видите страницу с двумя кнопками покупки, всё загрузилось правильно.
